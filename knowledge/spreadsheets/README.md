# Spreadsheet Knowledge

**Answers the question:**

> **Which reusable TraceForge guides govern spreadsheet engineering?**

## Guides

- [Spreadsheet Assessment and Business-Rule Discovery](Spreadsheet%20Assessment%20and%20Business-Rule%20Discovery.md) — How TraceForge assesses an existing workbook without confusing observed structure with intended business behavior.
- [Excel 365 Workbook Engineering](Excel%20365%20Workbook%20Engineering.md) — How TraceForge safely creates or modifies `.xlsx` workbooks whose target application is Microsoft Excel 365.

## Category Boundary

This category owns reusable practices for spreadsheet formats, applications, workbook structures, formulas, calculation behavior, compatibility, and validation.

It does not own the business meaning of a particular workbook. Payroll eligibility, budget policy, reporting definitions, employee rules, and other domain decisions remain in the project that defines them.
